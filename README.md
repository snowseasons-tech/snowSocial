# SnowSocial

SnowSocial is a single-business social content planner for drafting posts, scheduling a publishing queue, and reviewing monthly performance.

## Run the prototype

Open `index.html` in a current browser. Posts created in the composer are saved in that browser's local storage.

## Current scope

- Responsive dashboard for one business workspace
- Content planner and recent post list
- Post composer with channel selection, draft saving, and local scheduling
- Sample monthly reach and engagement visuals

The dashboard metrics and existing post examples are sample data. Creating a post only saves it locally; platform OAuth, secure token storage, scheduled publishing, and live analytics require backend implementation.
